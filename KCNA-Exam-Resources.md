# Kubernetes and Cloud Native Associate (KCNA) Exam Blueprint ☁️

This guide summarizes fundamental cloud-native concepts, container orchestration principles, and CNCF ecosystem standards required for the Kubernetes and Cloud Native Associate (KCNA) certification.

---

### 💡 High-Yield Study Strategies & Architectural Fundamentals

* **Understand the CNCF Landscape:** Memorize key project categories (Graduated, Incubating, Sandbox) across Telemetry (Prometheus), Mesh (Istio), Storage (Rook), and GitOps (ArgoCD/Flux).
* **Master Cloud Native Architecture:** Understand the trade-offs between monolithic, microservices, serverless, and edge computing models.
* **GitOps & Delivery Pipelines:** Differentiate between Pull-based (ArgoCD) and Push-based (Jenkins/GitHub Actions) continuous delivery mechanisms.
* **Observability Foundations:** Learn the 3 pillars of observability (Metrics, Logs, Traces) and how OpenTelemetry standardizes telemetry data collection.

---

### 🎯 Core Domain Breakdown

* **Kubernetes Fundamentals (46%):** Control plane vs Worker nodes, Pod lifecycle, Service discovery, Storage abstractions, and API resources.
* **Cloud Native Architecture (22%):** Microservices architecture, Serverless, Open standards (OCI, CNI, CSI, CRI), and Serverless paradigms.
* **Cloud Native Observability (16%):** Telemetry metrics (Prometheus), logging architectures, distributed tracing (Jaeger), and health checking.
* **Cloud Native Application Delivery (16%):** CI/CD concepts, GitOps principles, Helm packaging, and progressive delivery.
