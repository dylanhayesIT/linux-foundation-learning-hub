# Linux Foundation & Cloud Native Learning Journal 🐧⚡️

Welcome to my personal hands-on repository for Linux administration, container orchestration, and cloud-native system engineering! 

This repository serves as a knowledge base and practical lab ledger tracking real-world Linux Enterprise administration (LFCS/LFCE) and Kubernetes architecture (CKA/CKAD/CKS) practices.

---

### 💡 Core Engineering Principles

* **CLI First & Automation:** Prioritize shell scripting, imperative `kubectl` commands, and infrastructure as code over manual UI configurations.
* **Security & Hardening by Design:** Apply principle of least privilege, strict RBAC policies, network isolation, and Linux kernel security features (AppArmor/SELinux).
* **Systematic Troubleshooting:** Master core Linux diagnostics (`sysstat`, `journalctl`, `cgroups`) and Kubernetes pod/node debugging techniques.
