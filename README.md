A technical portfolio repository that fuses Linux Foundation cloud-native certifications with
Microsoft Azure, AI, Power Platform, and Dynamics-oriented engineering patterns.

## Fusion Topics
- Kubernetes Platform Engineering — CKA / CKAD / KCNA + Microsoft Azure
- Cloud-Native Security — CKS + Microsoft security and identity patterns
- Linux + Azure Operations — LFCS + Azure infrastructure patterns
- Observability & SRE — PCA + Azure monitoring patterns
- AI Workloads on Kubernetes — KCNA / CKA + AI-103 / AI-200
- Application Engineering — CKAD + PL-400
- Data & Analytics — PCA + PL-300
- Business Application Integration — CKA / CKAD + AB-210

## Technical contents
Python implementations, Kubernetes-style YAML concepts, JSON scenarios, pytest tests,
architecture documentation, and GitHub Actions CI.
